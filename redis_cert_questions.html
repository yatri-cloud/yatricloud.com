    Q22. You're inspecting the raw traffic between the client and server on an application using Redis. Which of the following are true about RESP (Redis Serialization Protocol)?

    Choose 2 answers

    ARESP traffic cannot be inspected with standard networking tools. Because the protocol uses a compact encoding, you need a specialized Redis protocol analyzer to read or send raw commands to the server.
    BRESP responses are type-prefixed — the first byte of each response indicates its wire type, such as + for simple strings, - for errors, and : for integers. This allows parsers to determine how to read each response from the byte stream.✓
    CRESP encrypts all traffic between the client and server by default, so no additional TLS configuration is needed to secure Redis connections in production.
    DEach Redis client library uses its own proprietary wire format to communicate with the server, and RESP is only used internally within the server to serialize data to disk.
    EClients send commands to the Redis server as RESP arrays of bulk strings. For example, SET mykey myvalue is transmitted as an array of three bulk strings: SET, mykey, and myvalue.✓
    Answer: B, E
